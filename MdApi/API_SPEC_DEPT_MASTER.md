# API SPEC — Master Data ของใบแจ้งเรื่อง GA / IM / AF / SV / SQA / PS

สถานะ: **รอ backend** — หน้าเว็บ (ฟอร์มสร้างใบแจ้งเรื่อง) ต่อไว้ให้แล้ว
ยิงทันทีที่เปิดฟอร์มของแผนกนั้น ถ้ายังไม่มี endpoint ฟอร์มจะขึ้นข้อความ
"โหลดตัวเลือกของแผนก X ไม่สำเร็จ" พร้อมปุ่ม "ลองใหม่" ใต้ช่องนั้น (ไม่มีรายการสำรองในโค้ด — ดู CLAUDE.md)

## 1. Endpoint

```
GET /api/v1/MasterData/{dept}      dept = ga | im | af | sv | sqa | ps
Authorization: Bearer <token>
```

หนึ่งเส้นต่อหนึ่งแผนก คืน **ก้อนเดียวหลายชุด** (แบบเดียวกับ `/MasterData/it` · `/pl` · `/cr` ที่มีอยู่แล้ว)

## 2. Response

```jsonc
{
  "sections":       [ { "code": "HV", "name": "รถใหญ่" }, { "code": "FL", "name": "รถยก" } ],
  "types":          [ { "id": 1, "name": "...", "section": "HV" } ],
  "requestTypes":   [ { "id": 1, "name": "...", "section": "HV" } ],
  "requestSubTypes":[ { "id": 1, "name": "...", "section": "HV", "typeId": 1 } ],
  "units":          [ { "id": 1, "name": "ชิ้น" } ],

  // เฉพาะ PS — ใบประเมินราคาที่อ้างถึงได้ (docNo เท่านั้นที่บังคับ)
  "estimates": [
    {
      "docNo": "EST-6901",          // เลขที่ใบประเมินราคา (ค่าที่ฟอร์มเก็บ)
      "docDate": "2026-09-05",      // วันที่ (ISO หรือจัดรูปแบบมาแล้วก็ได้)
      "machineType": "รถเครน 4 ล้อ", // ประเภทเครื่องจักร
      "engineModel": "6D16",         // รุ่นเครื่องยนต์
      "serialNo": "SN-7788",         // ทะเบียน S/N
      "machineNo": "CR-014",         // หมายเลขเครื่องจักร
      "machineModel": "KR-25H",      // รุ่นเครื่องจักร
      "system": "ระบบไฮดรอลิก",       // ระบบ
      "symptom": "ยกไม่ขึ้น",         // รายละเอียดอาการ
      "remark": "รออะไหล่จากผู้ผลิต"   // รายละเอียดเพิ่มเติม
    }
  ]
}
```

- ชุดไหนแผนกนั้นไม่มี **ไม่ต้องส่ง field นั้นมา** (หรือส่ง `[]`) — ฟอร์มไม่ได้ใช้ชุดที่ไม่ได้ประกาศไว้
- `section` / `typeId` = **ไม่บังคับ** ใส่มาเมื่อรายการนั้นแยกตามส่วนงาน / แยกตามประเภทเท่านั้น
  - ไม่ใส่ `section` → หน้าเว็บแสดงทุกแถวไม่ว่าเลือกส่วนงานอะไร
  - ไม่ใส่ `typeId` ใน `requestSubTypes` → แสดงทุกแถวไม่ว่าเลือกประเภทอะไร
- ⚠️ ถ้า `id` ซ้ำข้ามส่วนงาน (แบบ CR) ให้ส่ง `section` มาด้วยทุกแถว หน้าเว็บกรองด้วย section + typeId เสมอ

## 3. ชุดที่แต่ละแผนกใช้จริง

| แผนก | ฟิลด์ในฟอร์ม | ชุดที่ต้องส่ง |
|------|--------------|----------------|
| GA / IM | ประเภท | `types` |
| GA / IM | เรื่องที่แจ้ง | `requestTypes` |
| AF | เรื่องที่แจ้ง | `requestTypes` |
| SV | ส่วนงาน (HV/FL) | `sections` |
| SV | เรื่องที่แจ้ง | `requestTypes` |
| SQA | ส่วนงาน (HV/FL) | `sections` |
| SQA | ประเภทเรื่องที่แจ้ง | `types` |
| SQA | รายละเอียดที่แจ้ง | `requestSubTypes` (ผูกกับ `types` ผ่าน `typeId`) |
| PS | ประเภท | `types` |
| PS | เรื่องที่แจ้ง | `requestTypes` |
| PS | เลขที่ใบประเมินราคา (+ ข้อมูลเครื่องจักรอีก 9 ช่อง) | `estimates` |
| GA / IM / AF / SV / PS | หน่วยของ "รายการที่ขอ" | `units` (ไม่ส่ง = ใช้ชุดกลางของหน้าเว็บ) |

## 4. กติกาที่หน้าเว็บยึด

- **ค่าที่ฟอร์มเก็บและจะส่งกลับตอนสร้างใบ = `name`** ไม่ใช่ `id`
  (ยกเว้น **ส่วนงาน** ที่เก็บ `code` เพราะเป็นคีย์ที่ชั้นล่างอ้างถึง — เหมือน CR)
- เปลี่ยนส่วนงาน → ล้างค่าชั้นล่างทิ้ง, เปลี่ยนประเภท → ล้าง "รายละเอียดที่แจ้ง" ทิ้ง
- ค่าที่บันทึกไว้แล้วแต่ไม่มีใน master แล้ว ต้องยังแสดงเป็นตัวเลือกที่เลือกอยู่ได้ (ห้ามเด้งว่าง)

## 4.1 ใบประเมินราคาของ PS

- ผู้ใช้เลือก **เลขที่ใบ** อย่างเดียว อีก 9 ช่องเป็น **อ่านอย่างเดียว** หน้าเว็บเติมให้จากใบที่เลือก
  (เลือกใบใหม่ทับทั้งชุด, ล้างตัวเลือกก็ล้างทั้งชุด — ไม่มีทางที่ข้อมูลของคนละใบจะปนกัน)
- ค่าที่ฟอร์มเก็บและจะส่งกลับตอนสร้างใบ = `docNo` เท่านั้น อีก 9 ช่องเป็นข้อมูลแสดงผล
  (ตอนทำ endpoint สร้างใบ ไม่ต้องรับ 9 ช่องนั้นกลับ — อ่านจากใบประเมินราคาฝั่ง DB ได้เลย)
- ทุก field ยกเว้น `docNo` เป็น optional — ไม่มีข้อมูลก็ส่ง `""` หรือไม่ต้องส่ง ช่องนั้นจะขึ้นว่าง
- `docDate` ส่ง ISO มาได้ หน้าเว็บแปลงเป็น dd/MM/yyyy ให้ ถ้าจัดรูปแบบมาแล้วจะแสดงตามนั้น
- ค้นหาในคอมโบบ็อกซ์ได้ทั้ง `docNo` และ `machineNo` / `machineType` (แสดงเป็นข้อความรอง)
- ถ้ารายการใบประเมินราคาเยอะจนไม่ควรส่งมาทั้งก้อน บอกได้ — หน้าเว็บเปลี่ยนไปเรียก
  endpoint แยก (ค้นหาแบบ server-side) ได้ โดยไม่ต้องแก้รูปฟอร์ม

## 5. ยังไม่มี (ทำต่อเมื่อ backend พร้อม)

- **endpoint สร้างใบ** ของ GA / IM / AF / SV / SQA / PS — ตอนนี้กด "ส่งใบแจ้งเรื่อง" แล้วขึ้นหน้าสรุปอย่างเดียว
  ยังไม่ได้ยิง API (แบบเดียวกับที่ IT/PL/CR เคยเป็นก่อนมี endpoint)
- **endpoint แนบรูปของ SV** (`ImgPath1..3` แบบ IT/PL) — ฟอร์มมีช่องแนบรูป 3 รูปแล้ว
- ฟิลด์ที่ยังไม่มีที่เก็บฝั่ง DB: `customerType` (ลูกค้าภายนอก/ภายใน) + `customerDept` (แผนกลูกค้าภายใน)
  และ `attachedDocs` (สิ่งที่แนบมาด้วย — ติ๊กหลายข้อ) + `attachedOther` ของ SV
- PS: ต้องยืนยันว่า **"Plan วันที่ต้องการราคา"** ผู้แจ้งกรอกเอง หรือฝั่ง PS เติมทีหลัง
  (ตอนนี้ทำเป็นช่องไม่บังคับในฟอร์มผู้แจ้ง)
